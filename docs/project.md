# プロジェクト

このプロジェクトは、個人向けメモサービスです。
以下の機能を持ちます。

- Microsoft, Google などのソーシャルログイン, 同期
  - ID, パスワードでのログインは実装しない
- メモ入力機能
- 画像付きメモ投稿機能
- URL 投稿機能
  - URL を投稿した場合、内容取得の後、AI による内容要約を表示
- カテゴリ、タグ機能

## 思想

プロジェクトの開発は以下の思想の下にで行います。

- 必要な機能のみをミニマムに実装し、不要な機能を実装しない
- 保守性・開発持続可能性を高めることを最も重視し、メンテや機能改善を継続的に行えるようにする
- 運用負荷を低減することを重視し、ほぼノーコストで運用維持できるようにする
- 可読性を重視し、いつ見ても内容が理解できるようにする
- co-location の考え方でベースでディレクトリを分け、機能ごとに関心をまとめる
- UI・UX を重視し、自分が使って使いたいと思えるものを作る
